# Status

QALA Window 0.1.4 uses the 21 November 2026 OpenStreetMap snapshot. The exact Windows portable passed real Save and Open dialog tests, including cancellation in both and reopening the same route offline. A repeat export kept one local entry. [Windows dialog evidence](tests/evidence/native-dialog-0.1.4.json) · [Windows Location Services check in 0.1.3](tests/evidence/native-platform-location-0.1.3.json)

The GitHub release contains the portable Windows executable, SHA256 file and static web archive. The demo and captions are available with 0.1.2. [Open QALA Window](https://nuralikuzhagaliev.github.io/QALAWindow/) · [Release 0.1.4](https://github.com/NuraliKuzhagaliev/QALAWindow/releases/tag/v0.1.4) · [Demo release](https://github.com/NuraliKuzhagaliev/QALAWindow/releases/tag/v0.1.2)
