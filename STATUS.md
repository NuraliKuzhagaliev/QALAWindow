# Status

QALA Window 0.1.2 uses the 21 November 2026 OpenStreetMap snapshot and the Windows platform location service. The Windows permission flow was verified with a simulated device position. Physical GPS depends on permission and device signals.

The original Sites deployment is inaccessible. Source code, tests, documentation and OSM data are in the [private GitHub repository](https://github.com/NuraliKuzhagaliev/QALAWindow). The [private v0.1.2 release](https://github.com/NuraliKuzhagaliev/QALAWindow/releases/tag/v0.1.2) contains the Windows executable, checksum, static web archive and demo. The static edition passed local browser tests using the same path layout as GitHub Pages. Public visibility is awaiting the owner's choice.

See [0.1.2 verification](docs/RELEASE_0.1.2.md), [0.1.1 verification](docs/RELEASE_0.1.1.md), and [the original audit](AUDIT_REPORT.md).
