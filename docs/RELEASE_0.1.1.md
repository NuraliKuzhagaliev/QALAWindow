Windows portable не подписан. Старый файл 0.1.0 сохранён для восстановления, но содержит затронутый Electron 44.9.0. Формат pack и профиль совместимы, миграция не нужна.

Исправление включает доступ к Privacy на телефоне, соответствие времени пресета реальному интервалу, сброс Gemini по Pacific и исключение свободного запроса из ключа кэша и контекста объяснения. Лимит модели остаётся локальным для экземпляра. Полный срок физического удаления результатов с маршрутом из памяти сервера не обеспечен.

Подготовлен [Worker-архив](../release/qala-site-0.1.1.tar.gz) с прежней Site identity. Для публикации нужен доступ на запись к существующему проекту. После восстановления доступа следует передать подготовленный checkout через Sites source helper, сохранить версию и опубликовать её, затем выполнить анонимную проверку браузера и /api/weather. Если серверный запрос прогноза снова упадёт, проверить диагностическую запись qala_weather_unavailable с категорией отказа. Браузерный запрос проходит по фиксированным координатам Астаны.

Открыты GPS Windows, скачивание EXE с сайта, обновление OSM-снимка и проверка живой генерации Gemini. В этом выпуске платные API не вызывались.
