# QALA Window 0.1.3

Выпуск закрывает локально воспроизводимые замечания из [аудита](../AUDIT_REPORT.md).

| Пункт | Результат |
| --- | --- |
| A03 | Windows Location Services вернула реальную позицию на тестовом компьютере в выпусках 0.1.2 и 0.1.3. QALA принял её как стартовую точку. Проверка выполнялась без эмуляции и сохранила только статус. Способ определения координат Windows не установлен. |
| A07 | Для каждого участника доступны отдельные интересы, лимит непрерывной ходьбы, доступ без ступеней, розетки, тишина и пригодность для детей. Строгий режим принимает маршрут только при наличии данных о входе и всех плечах. Положительный сценарий проверен на синтетических данных. |
| A09 | Сообщения различают локальное сохранение, успешный экспорт, отмену и ошибку записи. Регрессия проверяет файловые операции и IPC с подставными ответами файлового диалога. |
| A10 | На 390 px виден вход в настройки конфиденциальности, атрибуция отделена от сводки. Fallback-экран проверен axe. Проверены переключатели EN, RU и KK. |
| A11 | В очереди объяснений остаются публичные факты и выбранные категории. Тикет можно использовать один раз в течение 120 секунд. Клиент применяет к исходному маршруту только текстовые поля. |
| A12 | Добавлен CI для типов, линтинга, детерминированных тестов и Pages-сборки. Порядок выпуска и отката описан в [руководстве](DEPLOYMENT.md). |

Веб-версия и Windows используют снимок `osm-2026-11-21-258b6326` с 120 местами и 5 403 путями. Покрытие без ступеней и актуальные условия на местности требуют отдельной проверки. Казахский текст ещё не проверял носитель. Live Gemini и HeiGIT не запускались. EXE без цифровой подписи.

Локально прошли [82 детерминированных теста](../tests/evidence/deterministic-0.1.3.tap), [Windows Location Services](../tests/evidence/native-platform-location-0.1.3.json), [запуск portable офлайн](../tests/evidence/portable-launch-0.1.3.json), [IPC, экспорт и очистка](../tests/evidence/native-clear-0.1.3.json), [прогноз и резервные сценарии](../tests/evidence/release-web-0.1.3-local.json), а также [статическая сборка](../tests/evidence/static-web-0.1.3-local.json). `npm audit --omit=dev` сообщил о нуле проблем. Полный аудит сообщил о шести умеренных замечаниях в дереве зависимостей упаковщика. Для сборки использовался [Node.js 22.23.5](https://nodejs.org/en/blog/release/v22.23.5).
