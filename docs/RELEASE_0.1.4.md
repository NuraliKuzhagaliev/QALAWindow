# QALA Window 0.1.4

Повторный экспорт одного маршрута использует ту же локальную запись. Если отменить сохранение в системном диалоге Windows, локальная копия остаётся в «Сохранённых прогулках». Чтение повреждённого файла показывает ошибку в той же панели и сохраняет список. Повторный экспорт импортированного маршрута с точной точкой снова запрашивает согласие.

Исправление закрывает A09 и дополняет A10 и A13 из [аудита](../AUDIT_REPORT.md). Предупреждения планировщика о времени работы, доступности и отсутствии подходящего маршрута переведены на русский и казахский. Windows-поставка содержит только нормализованный снимок и его отчёт. Локальные архивы и журналы сбора данных не включаются.

На исходной версии 0.1.3 настоящие системные окна Windows сохранили и открыли файл с тремя остановками, а также корректно обработали отмену сохранения и открытия. Повторный экспорт добавлял вторую запись. Проверка 0.1.4 использует ту же последовательность на отдельном профиле без личных файлов.

На локальной сборке прошли [83 детерминированных теста](../tests/evidence/deterministic-0.1.4.tap), [регрессия Windows с подставными результатами диалога](../tests/evidence/native-clear-0.1.4.json) и [браузерная регрессия](../tests/evidence/static-web-0.1.4-local.json). Проверка рабочих npm-зависимостей не обнаружила замечаний.

На местности ещё требуется проверить доступность маршрутов и входов. Казахский текст ожидает вычитки носителем. Живые Gemini и HeiGIT не вызывались, а опубликованное демонстрационное видео осталось в предыдущем релизе. Windows EXE без цифровой подписи.
